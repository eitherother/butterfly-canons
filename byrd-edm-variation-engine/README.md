# Byrd Variation Engine

_Byrd Variation Engine_ is an EDM engine for performing variations on the Kyrie from William Byrd's Mass for Four Voices. It can weave between ambient takes on the source recording and dance music built from beats cut out of the Kyrie itself.

The engine is recording-agnostic and released under the MIT License. For the first recording, I used the [performance by Ensemble Morales](<https://imslp.org/wiki/Mass_for_4_Voices%2C_T_1_(Byrd%2C_William)>), available under Creative Commons Attribution Only 3.0.
